# FinBERT Sentiment Analysis

This project performs sentiment analysis on financial news headlines using the FinBERT model from Hugging Face Transformers.

## Project Overview

The model analyzes financial news headlines and predicts whether the sentiment is:

* Positive
* Negative
* Neutral

The project also visualizes the sentiment distribution using a bar graph.

## Technologies Used

* Python
* Transformers (Hugging Face)
* FinBERT
* Pandas
* Matplotlib
* PyTorch

## Dataset

The dataset contains financial news headlines with sentiment labels.

## Features

* Financial news sentiment prediction
* Data visualization using bar charts
* NLP-based sentiment classification
* Real-world financial text analysis

## Output

The model predicts sentiments and generates a graph showing sentiment distribution.
